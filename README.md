# JumpAction_22RD601

このゲームはVisual Studioの中に、c++で作られたものだ。また、授業の先生から、素材と基礎コードを貰った。

(1)時限あり、操作がある程度に難しくする。挑戦がある。actゲームでした。そして、二つの目標があるどちらか達成しても、ゲームをクリアする。一つは4匹猫を倒す事。一つは右上の終点を到着する事。色んな操作を考え後、上手になれる。そして、ゲームクリアも簡単になる。 
 
(2) スペースキーでジャンプ更にタイミングに合わせて↑キーを押して二段飛ばしになる。Ｋキーを押すとスピードアップになる。タイムと命システムがあり、残りの時間と命を確認できる。踏切板があり、←→左右の方向を押すままに、踏切板に近寄って、タイミングに合わせて↑キーを押すと飛び出す事が出来る。だが踏切板は利用できる道具として同時に罠である。もし、ジャンプする最中に踏切板の上に着陸すれば、兎が踏切板に捕まえて動けない、猫に殺される事だけで罠から抜く事ができる。そうじゃないとタイム終了を待つだけ、厳しい罠でした。ですから、踏切板近くの猫を殺さない事は良い戦略かも。花もある。さわったらスピードアップ事ができて、更に、スピードアップ中に無敵する。もし初速度を持つ（歩くや走る状態）右方向キーを押すままに復活すれば右上の終点を何にもしていないよりもっと近くになれる。初速度を持つ方向キーを押すままに花と触るタイミングに合わせてスペースキーを押すと長い飛ばし出来る。運が良かったら、直接50％の道を飛ばして終点に近くする事が出来る。
